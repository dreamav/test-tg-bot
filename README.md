# Telegram-бот для онлайн-записи к мастеру маникюра

Полностью готовый Telegram-бот на Python с использованием асинхронной библиотеки **aiogram 3.x**, базы данных **SQLite** (`aiosqlite`) и планировщика задач **APScheduler**.

---

## 💅 Возможности бота

### Для клиентов:
* 📅 **Интерактивный календарь (на 1 месяц вперед):** визуальный выбор даты со свободными слотами (зеленые индикаторы 🟢).
* ⏰ **Выбор свободного времени:** показ только доступных слотов. Защита от одновременного бронирования и проверка правила: *1 клиент = 1 активная запись*.
* 👤 **FSM-сбор контактов:** пошаговый ввод имени и номера телефона (через кнопку контакта или вручную) с финальным подтверждением.
* 📋 **Раздел «Моя запись»:** просмотр актуальной записи и возможность отменить её в один клик. При отмене слот моментально возвращается в расписание.
* 💅 **Прайс-лист:** отображение цен в красивом HTML-формате.
* 🎨 **Портфолио:** переход в Pinterest мастера по inline-кнопке.
* ⏰ **Автонапоминания:** автоматическая отправка сообщения за 24 часа до визита.
* 📢 **Опциональная проверка подписки:** встроенная проверка обязательной подписки на канал мастера через `getChatMember`.

### Для мастера (Панель администратора `/admin`):
* 📅 **Управление расписанием:** выбор любой даты через админ-календарь.
* ➕ **Пакетное добавление слотов:** ввод времени через запятую или пробел (например: `10:00, 12:00, 14:30, 17:00`).
* 🗑 **Удаление свободных слотов:** выборочное удаление времени.
* 🔒 **Блокировка дней:** полное закрытие/открытие выбранной даты для записи.
* 📋 **Просмотр расписания:** список всех записей на дату с контактами клиентов.
* ❌ **Отмена записи клиенту:** возможность отменить запись с автоматическим оповещением клиента.
* 🔔 **Мгновенные уведомления:** оповещения о новых бронированиях и отменах приходят лично мастеру и в служебный канал с расписанием.

## 🚀 Инструкция по запуску

### 1. Получение токена и настройка `.env`
1. Откройте [@BotFather](https://t.me/BotFather) в Telegram, отправьте команду `/newbot` и скопируйте полученный **API токен**.
2. Узнайте свой Telegram ID через [@userinfobot](https://t.me/userinfobot) (числовое значение `Id`).
3. Откройте файл `.env` в корне проекта и укажите:
   ```ini
   BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
   ADMIN_ID=123456789
   ```

### 2. Установка зависимостей

**Вариант А (рекомендуется, через `uv`):**
```powershell
uv sync
```

**Вариант Б (через стандартный `pip`):**
```powershell
pip install -r requirements.txt
```

### 3. Запуск бота
```powershell
uv run bot.py
# или: python bot.py
```

### 4. Тестирование в Telegram Desktop
* Откройте Telegram Desktop.
* Найдите созданного бота по его `@username` и нажмите **Start** (или отправьте команду `/start`).
* Для доступа к панели мастера отправьте команду `/admin`.
